## 📚 Website Perpustakaan Sederhana

Website Perpustakaan Sederhana adalah aplikasi berbasis web yang dibuat untuk membantu pengelolaan dan penyajian informasi perpustakaan secara sederhana. Website ini dikembangkan menggunakan **HTML** sebagai struktur halaman, **CSS** untuk mengatur desain dan tampilan antarmuka, serta **PHP** untuk menangani proses dan logika pada sisi server. Project ini dibuat sebagai sarana pembelajaran dalam memahami dasar-dasar pengembangan website, khususnya penerapan frontend dan backend sederhana dalam sebuah aplikasi perpustakaan.
